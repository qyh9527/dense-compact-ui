# dense-compact-ui

紧凑高信息密度界面的设计、实现与评审指导：微间距与行式对齐、按角色分层的圆角、数字与字阶、强调色配额、窄屏重组与连续拼接，附 Zinc 深色默认主题（另有可切换的浅色附加版）与 CSS token。用于前端、UI、UX、界面、页面、组件、布局、样式、CSS、Tailwind、响应式、移动端适配、仪表盘、管理后台、工作台、编辑器、设计稿或界面评审相关任务，以及从参考图提炼空间语言、为已有项目整理一页 DESIGN.md。不用于不涉及界面呈现的纯 JS 逻辑、接口、构建配置问题，也不用于追求视觉张扬的海报和营销落地页。触发后先询问用户是否采用本风格；用户已明确要求紧凑或高密度风格时直接使用。

## 安装

把本仓库作为一个技能目录放进 Claude Code / Codex 的 skills 目录（仓库根即技能根，入口为 `SKILL.md`），或在 [cc-switch](https://github.com/farion1231/cc-switch) 中以 `qyh9527/dense-compact-ui` 添加。
