# 图表选型与密集看板

做图表、仪表盘、数据看板时读。看板里会自动刷新的部分另读 realtime.md。

## 通用规则

- 图例贴着图表；系列少时直接在线尾或柱顶标数值，省掉图例。多系列图表的图例可点击显示 / 隐藏系列（`aria-pressed`）。
- 网格线比数据弱（用 Border 色），坐标轴写单位和时间粒度；时间序列的粒度可切换（日 / 周 / 月或时间范围）。
- 分类色用独立色板（见 color.md）；颜色之外再加形状、线型或直接标注，色弱用户也能分辨。
- 提示框键盘可达；提供「表格视图」或文字摘要给屏幕阅读器；数据量大的图表提供 CSV 导出。
- 窄屏减少刻度、改横向条形；数据点超过 1000 先聚合，再下钻。
- 无数据、加载中、出错各有状态，不画空坐标轴。

## 按问题选图

| 想回答的问题 | 首选 | 备注 |
| --- | --- | --- |
| 随时间怎么变 | 折线 | 时间点 ≤12 时可用柱；不用饼图 |
| 类别谁大谁小 | 横向条形，按值排序 | 类别名短时可用纵向柱；不用 3D |
| 占比 | 堆叠条、100% 条 | ≤5 类时可用环形图；类别多不用饼图 |
| 分布 | 直方图、箱线图 | 样本少时直接画点 |
| 两个数值的关系 | 散点 | 第三个数值用点大小编码 |
| 目标完成度 | 子弹图、带目标线的进度条 | 不用占地大的仪表盘盘面 |
| 单个实时数值和走势 | 大号数字 + 迷你折线 | 迷你图不带坐标轴 |
| 多个对象同一指标的走势 | 小图组（共享坐标轴与刻度） | 不在一张图里叠十几条线 |
| 时间 × 对象的密集数值 | 热力图 | 配色阶图例和数值提示 |
| 流程转化 | 横向条或漏斗 | 标出每步转化率 |
| 地理分布 | 分级统计地图 | 只在地理位置本身有意义时用 |

## 高密下的图

- 嵌进表格的图：行内迷你图、行内条形（不带背景轨道）、状态色块；高度不超过行高减 6px。
- 小图组共享坐标轴和刻度，省掉重复的图例和轴标签。
- 坐标轴、刻度、标签用小一号字和 Muted 色；数据本身对比最强。
- 只标关键点的数值（最大、最新、异常），不全部标。
- 同一页图表的配色、单位、时间范围保持一致；时间范围控件放在页面级，联动所有图表。
- 数据点很多时先聚合（按分钟、小时），再提供下钻；大量点用 Canvas 渲染，不生成上万个 SVG 节点。

## 图表库（开发时去查）

| 场景 | 可选 |
| --- | --- |
| 通用业务图表、中文资料多 | ECharts |
| React 声明式 | Recharts、visx、Nivo |
| 海量时间序列、性能优先 | uPlot |
| 简单图表、依赖少 | Chart.js，或直接写 SVG |
| 定制可视化 | D3 |

- 项目已经用了哪个就沿用；新引入时选能满足需求的最轻的一个。
- 去查：该库怎么把 `--dc-*` 颜色接进主题、暗色主题、无障碍（ARIA、数据表格替代）、按需引入减小体积。
