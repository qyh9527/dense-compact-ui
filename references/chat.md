# AI 对话界面

做聊天、AI 助手、智能体工作台、带对话区的编辑器时读。流式输出的库和组件变化快，末尾「去查」给出关键词，开发时按当前文档核对。

## 布局

- 三个区域：会话列表（左，可收成图标栏，窄屏改抽屉）、对话区（中）、上下文或产物面板（右，可选，窄屏改抽屉）。
- 对话正文限宽：英文约 65–75 字符，中文约 35–40 字；对话区再宽也不拉满。表格、代码块可以比正文宽。
- 高密工作台里不用大圆角气泡：用户消息用浅底色或右对齐短块区分，助手回复全宽排版，靠标签和间距分轮次。
- 同一发送者的连续消息间距小，换人时间距大。
- 工具调用、思考过程默认折叠成一行摘要（名称、状态、耗时），可展开看参数和结果；失败的那一行直接显示原因。

## 输入框

- 固定在对话区底部，随内容自动增高，到约 6–8 行后内部滚动；附件和上下文标签显示在输入框上方，可单独移除。
- 发送和停止在同一位置切换；生成中输入框仍可编辑，下一条排队或等待由产品决定，但要说清楚。
- Enter 发送、Shift + Enter 换行；**输入法组合中（`event.isComposing` 为真或 `keyCode === 229`）按 Enter 不发送**，否则中文用户选词时会误发。
- 发送失败时消息保留在列表里并标「发送失败」，给重试；输入框内容不清空，直到确认已送达。
- 手机上输入框贴着软键盘，避开安全区；做法见 responsive.md。

## 流式输出与滚动

- 只在用户位于底部时跟随新内容（距底部约 60px 内算在底部）。用户向上滚、选中文字、用键盘移动时停止跟随，显示「回到最新」按钮，点击后恢复跟随。每轮新回复开始时重置跟随状态。
- 新一轮开始时，把用户这条消息滚到视口上部，回复在它下方展开，并保留一点上一轮的内容作为上下文。
- 流式内容按帧合并写入（`requestAnimationFrame`），不对每个片段调用平滑滚动，避免多段滚动动画叠加。
- 代码块、图片、公式渲染完成后高度会变：图片预留尺寸，用 `ResizeObserver` 在仍跟随时补滚到底；不跟随时保持阅读位置不动。
- Markdown 流式渲染时，未闭合的代码块、表格先临时闭合渲染，不在每个片段到达时整段重排闪烁。
- 停止生成：移除光标，消息末尾标「已停止」，给「继续」或「重试」；网络中断同样标出未完成，并给重试。
- 光标、打字指示只是视觉元素，加 `aria-hidden="true"`；减少动态效果时光标不闪烁。

## 消息与操作

- 每条助手回复有复制、重新生成、反馈；用户消息可编辑后重发。鼠标设备悬停显示，键盘聚焦时同样显示，触屏常显或放进长按菜单。
- 编辑旧消息或重新生成会产生分支：显示分支切换（‹ 2 / 3 ›），不静默覆盖原回复。
- 代码块：顶部显示语言和复制按钮；长代码限高并可展开；横向滚动，不自动换行。
- 引用、来源链接显示域名或标题，在新标签页打开；需要用户确认的操作（执行命令、写文件）用明确的「允许 / 拒绝」按钮，并写清会做什么。
- 错误、额度用尽、内容被拦截各有明确文案和下一步，不只显示红色感叹号。

## 会话列表与长会话

- 会话按时间分组（今天、昨天、7 天内、更早）；标题自动生成并可改名；支持搜索；删除可撤销。
- 重新打开会话时定位到最后一轮用户消息，回复在其下方，而不是跳到最底部。
- 长会话的消息行加 `content-visibility: auto` 和 `contain-intrinsic-size`，或用虚拟列表；向上加载更早的消息时保持当前看到的那一行不动（Safari 不支持 `overflow-anchor`，需要手动补偿滚动位置）。
- 消息有稳定的 ID，可以生成链接直接跳到某条。

## 无障碍

- 消息列表用 `role="log"` 或有序列表，结构可逐条浏览。
- 流式文本所在的节点不设 `aria-live`，否则屏幕阅读器会逐字播报。另放一个视觉隐藏的 `role="status"` 区域：开始时播「正在生成」，结束时播「回复完成」（短回复可播全文），出错用 `assertive`。
- 发送后焦点留在输入框，开始和结束生成时都不抢焦点；提供「跳到最新回复」入口。
- 「停止生成」在整个生成过程中可聚焦、有名称；消息操作按钮的名称写清对象（「复制这条回复」）。

## 去查

- 跟随到底部的滚动：「stick to bottom chat」，React 有 use-stick-to-bottom 一类的库，Vue 有同类组合式函数；shadcn/ui 的 Message Scroller 说明了各种滚动边界情况。
- 流式 Markdown：「streaming markdown renderer」，确认未闭合语法的处理和增量渲染。
- 现成的对话组件：「AI SDK UI」「assistant-ui」，或项目所用框架的同类库；先确认是否只提供无样式基础组件，以便套用本技能的 token。
- 屏幕阅读器播报：「accessible AI chat streaming aria-live」。

## 检查

- [ ] 生成过程中向上滚动，阅读位置不被拉回；点「回到最新」后恢复跟随
- [ ] 用中文输入法选词时按 Enter 不会发送
- [ ] 生成中途停止、断网：消息标为未完成，能重试，输入不丢
- [ ] 代码块、图片渲染后阅读位置不跳
- [ ] 读屏软件只在开始和结束时播报；发送后焦点仍在输入框
- [ ] 几百条消息的会话滚动不卡顿，重新打开定位到最后一轮
