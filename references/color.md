## 通用规则（任何主题都适用）

- **彩色只出现在有语义的地方。** 普通操作、面板、导航用中性色；区域差异靠名称、位置、状态和少量标记，不按业务模块分配不同主题色。
- **强调色配额：总面积 ≤10%。** 只给主操作、当前选择、关键数字（如总额）和「我 / 当前用户」这类高亮。计入配额的是纯语义色的填充、文字和图标；选中底、浅色语义底（`--dc-selection`、`--dc-*-subtle`）和中性主按钮不计入。按设计稿的默认状态量，不按用户选中的行数量。
- **数据可视化分类色单独一套**：`tokens.css` 的 `--dc-viz-1` 到 `--dc-viz-5`，第 6 类起并入 `--dc-viz-other`（「其他」），系列更多时改用小图组。分类色只在图表、分布条里用，不拿来当按钮或状态色；按顺序取色，相邻系列明度不同。
- **系列本身就是状态时用状态色。** 成功 / 重试 / 失败这类系列用 Success / Warning / Danger，配图例文字或直接标注；同一张图里不再混入分类色。其余情况状态色不进图表。
- **不用纯黑纯白。** 深色底用深灰（本技能画布 `#191A1B`），亮文字用近白（如 `#FAFAFA`）。
- **中性色可以带一点色相**，与品牌呼应（如 OKLCH 里色度 0.005–0.03 的品牌色相灰阶）。只调色相、不加饱和度，结构仍靠明度差。
- 只为真实层级增加表面色；同类面板共享色系。
- **关闭的条目仍是内容。** 开关已关、已停用的条目用户照样要扫览和比较：名称至少用 Text Muted（≥4.5:1），关闭状态靠开关和状态标记表达；Text Dim 和降低透明度只给当前不可操作的控件。
- **整页一个主题。** 局部区域不反色：深色页面里不夹一块浅色区，反之亦然。深浅切换是整页一起切。
- **阴影带底色色相，只给真实抬升的浮层。** 浅色主题不用纯黑阴影；起点是 `tokens.css` 的 `--dc-shadow-overlay`。

| 走偏 | 改成 |
| --- | --- |
| 每个按钮、每个卡片标题都用品牌色 | 普通操作中性；品牌色只给主操作和当前选择 |
| 图表系列色复用成功/警告/错误色，系列却只是不同类别 | 用 `--dc-viz-*`；系列本身是成功 / 失败时才用状态色 |

## Zinc Graphite Dark（默认主题）

来自用户设计文档的自定义混合主题：Zinc 灰阶组织结构，GitHub Dark 风格语义色表达交互与状态。画布按用户偏好从 `#09090B` 提亮到 `#191A1B`，其余表面随之提亮一档，层级差与原版相当。不是任何设计系统发布的同名官方主题。新界面未指定主题时默认用它；已有主题照旧。

### 中性结构

| Token | 色值 | 用途 |
| --- | --- | --- |
| Canvas | `#191A1B` | 最外层画布 |
| Subtle | `#1D1E20` | 过渡底色，按需 |
| Surface | `#212225` | 工作面板、常规内容 |
| Raised | `#28292C` | 浮层、抬升表面 |
| Hover | `#2E2F33` | 短暂悬停 |
| Pressed | `#28292C` | 短暂按压，必要时加内描边 |
| Border | `#2E2F33` | 装饰分隔线、面板边界 |
| Border Strong | `#45464B` | 较明显的结构边界 |
| Control Border | `#7A7B82` | 输入框等靠边界辨识的控件（对 Canvas 4.1:1、Surface 3.8:1） |
| Text | `#FAFAFA` | 标题、重要信息 |
| Text Secondary | `#D4D4D8` | 正文、常规标签 |
| Text Muted | `#A1A1AA` | 元数据、提示、占位 |
| Text Dim | `#71717A` | 禁用或纯装饰；不作常态小字 |

### 语义色

| 角色 | 色值 | 用于 |
| --- | --- | --- |
| Accent / Info | `#58A6FF` | 链接、当前交互对象、选中标记、焦点 |
| Success | `#3FB950` | 成功、在线、完成 |
| Warning | `#D29922` | 待关注、风险 |
| Danger | `#F85149` | 失败、错误、危险操作；浅红底上的文字用 ink `#FF7B72`（5.5:1） |
| Special | `#A371F7` | 少量特殊类别，按需 |

- 默认按钮用中性表面；主操作可用明亮的中性按钮。彩色填充只在明确需要强调时用，并核验前景对比：蓝底不默认配白色小字。
- 语义优先用状态文字、图标、细边线和小面积浅色底承载。

### 状态

- **Selected**：少量蓝色混合底 + 固定位置的标记或边线；边线预留空间，避免布局位移。
- **Focus**：`--dc-focus-width`（2px）Accent outline，位置与 Selected 标记分开。默认外描边（`--dc-focus-offset`）；元素在滚动容器、截断单元格或满宽行里时改用内描边（`--dc-focus-offset-inset`），否则会被 `overflow` 裁掉。背景是 `--dc-primary-bg` 的主按钮保持外描边：Accent 画在近白主按钮上只有 2.4:1。对比度按焦点环实际画在上面的颜色算：内描边比元素自身背景，外描边比父容器背景。
- **Hover / Pressed** 短暂，**Selected** 持续，三者不用同一种高亮。
- 成功、警告、错误同时有文字或图标，颜色不单独承担含义。

### 对比度

- `#2E2F33`、`#45464B` 是弱结构线，不能当作满足必需控件边界的 3:1。输入框主要靠边界辨识时用 Control Border。
- 混合背景、选中背景、浮层上的文字分别实测配对。

## Zinc Light（可切换的浅色附加版）

Zinc Graphite Dark 的浅色镜像：同一套 token 名，纯中性灰阶 + Primer 浅色语义色。**默认只做深色**，不主动附带浅色和切换逻辑；用户明确要浅色、项目已是浅色，或要求深浅切换时才加。

### 默认主题与切换

默认主题只在这里定，其他文件引用这一节：

- **默认主题 = 项目默认**：新建项目是深色；已是浅色的项目改版后仍默认浅色，老用户不被换掉熟悉的底色。
- **提供切换时**：选项为「跟随系统 / 深色 / 浅色」，用户没选过时用项目默认主题；「跟随系统」是用户主动选的一项。系统没设置偏好时浏览器报告 `light`（Media Queries 5 已删掉 `no-preference`），所以「跟随系统」不能兼当「默认深色」。
- 在根节点切 `data-theme="zinc-graphite-dark"` / `"zinc-light"`，布局与密度变量不动。
- 记住用户的选择（如 `localStorage`），在首屏渲染前按「存储的选择 → 项目默认」算出 `data-theme`，避免先闪一下另一套主题；选了「跟随系统」时监听 `prefers-color-scheme` 实时切换。
- 切换入口用标准热区，带可访问名称并标明当前状态：二态按钮用 `aria-pressed`；三选一用原生单选或 `role="radiogroup"` + `aria-checked`。

### 中性结构

| Token | 色值 | 用途 |
| --- | --- | --- |
| Canvas | `#F0F0F2` | 最外层画布，比面板暗一级 |
| Subtle | `#F5F5F7` | 过渡底色，按需 |
| Surface | `#FAFAFA` | 工作面板、常规内容 |
| Raised | `#FCFCFC` | 浮层、输入框底；配边框或阴影区分 |
| Hover | `#ECECEF` | 短暂悬停 |
| Pressed | `#E4E4E7` | 短暂按压 |
| Border | `#E4E4E7` | 装饰分隔线、面板边界 |
| Border Strong | `#D4D4D8` | 较明显的结构边界 |
| Control Border | `#85858D` | 输入框等靠边界辨识的控件（对 Canvas 3.2:1、Surface 3.5:1） |
| Text | `#18181B` | 标题、重要信息 |
| Text Secondary | `#3F3F46` | 正文、常规标签 |
| Text Muted | `#5F5F69` | 元数据、提示、占位（对 Canvas 也过 4.5:1） |
| Text Dim | `#A1A1AA` | 仅禁用或纯装饰（2.5:1，不承载信息） |

### 语义色

| 角色 | 色值 | 浅底上的文字（ink） |
| --- | --- | --- |
| Accent / Info | `#0969DA` | `#155DBA` |
| Success | `#1A7F37` | `#1F6E34` |
| Warning | `#9A6700` | `#855A13` |
| Danger | `#CF222E` | `#B1272D` |
| Special | `#8250DF` | `#7048BE` |

- **主操作用近黑按钮**（`#18181B` 底 / `#FAFAFA` 字），蓝色只留给选中、链接和焦点，不占强调色配额。
- **浅底上的语义文字用 ink 色。** 语义色直接放在 10–13% 浅底上只有约 4.0–4.4:1，放在 Canvas 上约 4.3–4.7:1，不能稳定过 4.5:1；ink 是语义色向 Text 混入 15%（oklab）后的值，对 Canvas 和 Surface 全部 ≥5.3:1。选中态文字、状态标记都用 ink（`--dc-*-ink`）；放在 Surface 上的链接和图标可直接用语义色。
- 浅底混合比例：Selection 10%、Success 11%、Warning 13%、Danger 10%，各自混入 Surface。
- 选中、焦点、悬停的规则与深色主题相同。

## 集成

- 变量起点在 `assets/tokens.css` 的主题段。密度变量独立；切换主题不改布局。
- shadcn/ui：按项目当前变量映射 `background`、`card`、`foreground`、`muted-foreground`、`border`、`ring`。它的 `accent` 通常是中性悬停表面，别和蓝色交互信号混用。先确认变量存的是完整颜色还是 HSL 等通道值，再粘贴。
