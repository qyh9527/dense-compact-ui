## 布局与分栏

- 常见排布：左侧导航或大纲 | 中间编辑区 | 右侧属性面板，底部可选预览或日志面板。编辑区优先，其余面板可以折叠。
- 折叠后的侧栏保留一条约 32–40px 的窄条（放图标和展开按钮），占位而不是浮在内容上。
- 分隔条可拖动调整宽度：`role="separator"`，带 `aria-valuenow` / `aria-valuemin` / `aria-valuemax` 和指向主面板的 `aria-controls`；方向键调整，Enter 折叠 / 恢复，双击恢复默认宽度。每个面板有最小宽度；宽度和折叠状态记住。
- 窄屏时属性面板和侧栏改为抽屉或底部面板，一次只打开一个，不挤压编辑区。
- 编辑和预览并排时，预览更新做防抖（约 150–300ms）；滚动同步做成可开关的选项。

## 属性面板

- 内容跟随当前选中的对象，选中别的对象时整体切换；什么都没选时显示一句说明（「选中一个对象来编辑属性」），不留一片空白。
- 多选时只显示共同属性，取值不同的字段标「混合」，不显示为空。
- 面板宽度和字段位置固定：切换对象时面板不变宽，输入框不跳位；标签列固定宽度，数值列对齐。
- 改值立即生效并在编辑区预览；数字字段支持方向键增减（Shift 加大步长），单位写在字段内。
- 分组可折叠并记住展开状态。已修改的值与默认值区分开（标记或字重），单项可「恢复默认」。
- 选择由点击决定，不跟随悬停；如果提供悬停预览，样式要和已选中明显不同。

## 保存、撤销与冲突

- 保存状态放在固定位置（标题旁或状态栏）：「已保存」「保存中…」「有未保存的修改」「保存失败 · 重试」；标签页标题上用圆点表示未保存。
- 自动保存和草稿规则见 forms.md 的「草稿与离开」。
- 撤销 / 重做覆盖所有编辑：文字输入、属性面板修改、删除、拖拽排序。连续输入合并成一步。快捷键 Ctrl/⌘ + Z、Ctrl/⌘ + Shift + Z（Windows 另支持 Ctrl + Y）。
- 同一对象在别处被修改（另一个标签页、另一台设备）时，提示冲突并给「保留我的」「使用新版本」「对比」，不静默覆盖任何一方。

## 命令与键盘

- 提供命令面板（Ctrl/⌘ + K 或 Ctrl/⌘ + Shift + P）：列出所有命令和对应快捷键，按当前焦点区域过滤，也是学习快捷键的入口。
- F6 在主要区域（导航、编辑区、属性面板、底部面板）之间切换焦点，各区域记住自己的焦点位置。
- 底部状态栏显示当前文档的信息（字数、光标位置、校验问题数），点击跳到详情。
- 编辑区内的快捷键优先于全局快捷键；不占用浏览器常用快捷键（见 patterns.md 的「快捷键与拖拽」）。

## 条目编辑

适用于左侧条目列表 + 右侧编辑区的界面（如角色卡、词条、配置项）。

- 切换条目前自动保存当前条目，不弹「是否保存」；保存失败时停在原条目并提示。
- 长文本字段用随内容增高的文本框，或可展开到整个编辑区的编辑器；显示字数或 token 数和上限，接近上限变色。
- 标签、键值对、子条目列表这类结构化字段：就地增删，拖拽排序同时提供「上移 / 下移」，删除可撤销。
- 导入导出：支持拖入文件和按钮选择；导入前预览并校验，列出被忽略或转换的字段，确认后才写入。
- 列表里标出有未保存修改或校验错误的条目。

## 去查

- 可拖动分栏：「<框架> resizable panels」，确认支持键盘操作、最小宽度和持久化。
- 撤销 / 重做：「undo redo command pattern」，或所用编辑器内核自带的历史记录。
- 命令面板：「command palette component」（如 cmdk 一类的库）。
- 编辑器内核（CodeMirror、Monaco、ProseMirror / Tiptap、Lexical）：查它的主题和行高配置入口，把 `--dc-*` 颜色和字号接进去。

## 检查

- [ ] 拖动分隔条和用方向键都能调宽度，刷新后宽度和折叠状态保留
- [ ] 连续切换几种不同对象，属性面板不变宽、输入框不跳位
- [ ] 多选时不同取值显示「混合」
- [ ] 改动后关闭标签页有提示，或已自动保存；撤销能撤回属性面板的修改
- [ ] 窄到 360px：属性面板变成抽屉，编辑区仍可用
