# 实时数据

做会自动刷新的看板、监控、任务队列、日志流、协作状态时读。表格本身的结构见 tables.md，数字变化的高亮动效见 motion.md。

## 更新节奏

- 高频推送先合并：数值类每秒最多渲染一次，或在 `requestAnimationFrame` 里批量写入；只更新变化的单元格，不整表重绘。
- 页面在后台标签页（`document.visibilityState === "hidden"`）时降频或暂停，回到前台后一次补齐。
- 自动刷新的内容给「暂停 / 继续」开关：持续变化的信息要能停下来读（WCAG 2.2.2）。

## 不打断正在看的人

- 用户正在选择、悬停、编辑某行或已经滚离列表顶部时，新数据不插到可见区域上方把内容顶走；改为顶部显示「N 条新数据」按钮，点了再插入并滚到顶部。
- 按某列排序时，该列的值变化不立即重排（行会跳走）；标出「排序可能已过期」，或等用户下一次操作时再重排。
- 正在编辑的值不被推送覆盖：推送来的新值先以提示形式出现，由用户决定采用还是保留自己的。

## 数值与时间

- 数字变化时直接替换，短暂高亮底色（不超过 1 秒）；涨跌用 `+` / `−` 符号加颜色，不只靠颜色。
- 相对时间（「3 分钟前」）用 `Intl.RelativeTimeFormat`，并定时刷新；悬停或聚焦时给出绝对时间。
- 千分位、货币、百分比、日期统一用 `Intl.NumberFormat` / `Intl.DateTimeFormat` 按界面语言格式化，不手拼字符串。

## 连接状态

- 在固定位置（标题旁或状态栏）显示连接状态：「实时」「重连中…」「已断开 · 最后更新 14:32:05」。
- 断开后数据保留但标为过期（降低对比、显示时间戳），不假装仍是最新。
- 重连用指数退避；恢复后补齐断开期间的数据，按 ID 去重，不重复也不漏。
- 用户自己的操作先在界面上生效（乐观更新），服务端失败时回滚并给出原因和撤销或重试。

## 播报

- 实时变化的计数和状态，用一个 `aria-live="polite"` 区域播报完整短语（「3 个任务失败」），不只播数字；不移动焦点。
- 高频变化做节流，只播报有意义的变化（状态翻转、越过阈值），不逐条播报每次刷新。
- 严重告警才用 `assertive` 或 `role="alert"`。

## 检查

- [ ] 每秒几十条推送时界面不卡顿，CPU 占用不持续打满
- [ ] 正在读某一行或编辑时，内容不被新数据顶走
- [ ] 断网 30 秒再恢复：状态提示正确，数据补齐且没有重复行
- [ ] 能暂停自动刷新；切到后台再切回，数据一次补齐
- [ ] 屏幕阅读器只播报有意义的变化，不刷屏
