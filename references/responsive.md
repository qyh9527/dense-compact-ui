# 窄屏与区域关系

## 先认关系，再排版

响应式改的是呈现方式，要保住的是信息关系。区域数量和组件类型从任务推导。

| 关系 | 宽屏 | 窄屏 |
| --- | --- | --- |
| 需持续互相参照 | 紧密邻接，上下文可见 | 改方向，必要时纵向连续拼接 |
| 主任务 + 辅助上下文 | 按任务分主次面积 | 主区拿面积，辅助区留可恢复的锚点 |
| 有先后或依赖 | 稳定的阅读与操作顺序 | 重排后语义顺序不变 |
| 同类重复 | 共享网格与节奏 | 按宽度改列数或内容形态 |
| 职责独立 | 清楚分组或独立入口 | 导航、切换或普通内容流 |

单区域直接重排内部；独立任务分开呈现。

## 硬规则

- **Tab / 分段控件单行横滑，不 wrap 成多行。** 当前项滚入可见；可以在溢出侧加渐隐提示还有内容。
- **手机窄屏的表格收起次要列，核心指标留在屏内。** 核心数据不靠横向滚动查看；被收起的字段进展开行或详情视图。触屏平板（宽度在手机和桌面之间）按可用宽度定：全部列放得下就全显示，放不下就按手机规则收列，热区保持 44px。只用于桌面鼠标的项目保留全部列，按 tables.md 的「结构与列宽」整表横向滚动。
- **窄屏布局切换用断点外壳**：宽屏常驻侧栏，窄屏换成顶栏 + 抽屉；内容在外壳内的唯一滚动区里滚。手机目标宽度 360–430px。
- **触屏要有按压反馈**：`:active` 状态即时可见，不依赖 hover。可点元素加 `touch-action: manipulation`。
- **固定栏避开安全区**：顶栏、底部操作条用 `env(safe-area-inset-*)` 补内边距（页面 viewport 需带 `viewport-fit=cover`）；滚动内容给固定栏留出同样的位置，不被挡住。
- **横屏两侧也有安全区。** 贴左右边的侧栏、会话列表、表格首列补 `padding-left: max(<原内边距>, env(safe-area-inset-left))`，右侧同理。内容在外壳内唯一滚动区里滚时，直接在外壳根节点补四边 inset 最省事；整页文档滚动时根节点的 padding 管不到吸顶栏，`position: sticky` 的栏改写 `top: env(safe-area-inset-top)` / `bottom: env(safe-area-inset-bottom)`，并给让出的那段填上底色，多层吸顶的 `top` 逐层累加。

| 走偏 | 改成 |
| --- | --- |
| 6 个 Tab 在 360px 下折成 2 行 | 单行横滑 |
| 8 列表格整体横滑 | 保留名称 + 核心指标 2–3 列，其余进展开行 |

## 连续拼接

多个区域参与同一任务、用户要频繁在它们之间对照、联动或跨区操作时，保留邻接关系：宽屏横向相邻，窄屏纵向连续。顺序按依赖、阅读路径或用户既有的空间记忆定，换方向时不变。

- 相邻区域像一个被分区的整体：共享表面、边界、字体和操作节奏，区域间用 2–8px 拼接缝或细边界。
- 实际共边：组合外轮廓留圆角，内部接缝为 0，重复边框合并。有间距的独立区域各留圆角。重排后按新方向重判边角。
- 紧密邻接不等于必须合并成一个容器。
- 拼接缝要承担拖拽调比例、折叠等交互时，给它独占且够大的热区和可发现的入口；静态缝只是边界。

每个区域按需组合：身份锚点（区域名、当前对象、状态）、局部操作、内联状态、内容窗口。简单区域不必配齐整套工具。共享操作放在更高作用域。

## 面积

- 按阅读、输入和当前操作的需要分面积，允许不对称。
- 高度不足、文字放大或键盘弹出时，先压缩低优先级区域，但保留身份、状态和恢复入口；被压缩的区域保持内部状态。
- 最小面积绑定到实际内容：一旦无法辨识、输入或操作，就换结构，而不是继续挤。只有任务真的需要同时看多个区域时，才坚持多窗口同时展开。

## 滚动

- 连续内容和简单页面用页面滚动；需同时保持多个位置时，相关区域各自滚动。
- 固定或粘性部分只留持续需要的入口，并计算它们占掉的高度。
- 局部滚动的写法：父容器有真实尺寸约束 → 弹性子项设 `min-block-size: 0` / `min-inline-size: 0` → 内容区 `overflow: auto`。保留键盘进出滚动区的路径。
- 根界面以 `100dvh` 为起点，嵌入界面跟随父容器。安全区和软键盘要按实际可视视口处理，别指望一个 CSS 单位全部解决。

## 跨断点连续性

- 换断点、展开、切换时保留选中项、输入进度和合理的滚动位置。
- 联动关系有可见状态和准确反馈。
- 拖拽、调比例等直接操作有按钮或键盘等效入口。
- 记忆用户的区域尺寸和顺序时，按方向和可用空间换算并限制范围。
