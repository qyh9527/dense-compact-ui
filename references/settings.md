# 设置页与偏好面板

做应用设置、偏好面板、账户与工作区配置时读。字段本身的写法见 forms.md。

## 目录

- 结构
- 控件选择
- 保存方式
- 作用域与默认值
- 危险操作
- 检查

## 结构

- 左侧分类导航 + 右侧内容；窄屏时分类导航变成首页列表，点进子页面，返回时回到原位置。
- 分类按用户的任务命名，约 4–8 个；不用「其他」「杂项」。入口名称和子页面标题一致。
- 每个设置一行：标签 + 一行说明 + 控件在行尾靠右。说明写当前状态或开启后会怎样，不复述标签。
- 分组用小标题 + 1px 分隔线，不给每个设置单独包一张卡片，也不在每个设置之间加分隔线。
- 「标签 + 说明 + 控件」型的设置行限宽约 640–720px（限的是设置行，不是整个内容区），短标签和行尾控件之间不会隔出大片空白；整行悬停高亮，点标签也能操作控件，视线能横向对上。以列表或表格总览为主的管理页按 tables.md 和 layout-density.md 的「行模型」铺宽。
- 常用的放前面；很少用的放进「高级」分组，默认收起。
- 设置项超过约 15–20 个时提供搜索：匹配标签、说明和同义词（搜「2FA」能找到「两步验证」）；结果显示所在分类；每个设置有可分享的链接（URL hash），打开时滚到并高亮该项。
- 不把常用操作放进设置：只在某个功能里用的选项，放在该功能旁边。

## 控件选择

- 开关只用于改了立即生效的二元设置；需要点保存才生效的二元选项用复选框。
- 2–5 个互斥选项用单选或分段控件，更多用下拉。
- 依赖其他设置的项放在它下方；不可用时保持可见并说明原因（「需要先开启同步」），不直接隐藏。
- 主题、语言、时区默认「跟随系统」。

## 保存方式

- 低风险设置改了即生效：控件旁短暂显示「已保存」；保存失败时控件恢复原值并说明原因。
- 高风险或多字段联动的设置（账户信息、网络代理、权限、计费）用显式保存：底部固定一条保存栏，显示「有 N 项未保存」和「保存」「放弃修改」；离开页面前提示。
- 同一个分组里不混用两种保存方式；一个页面里两种都有时，显式保存的分组要明确标出。
- 需要重启或重新登录才生效的设置标明这一点，并给出「立即重启」入口。

## 作用域与默认值

- 改过的设置做标记（如左侧细竖线），可以单项「恢复默认」；整页「恢复默认」需要确认或可撤销。
- 有多层作用域（用户 / 工作区 / 项目）时，页面顶部显示当前编辑的作用域并可切换；被其他作用域覆盖的值要标出是被哪一层覆盖的。
- 用户改过设置后，应用的新版本不悄悄重置它。

## 危险操作

- 删除账户、清空数据、重置全部放在页面最下方单独一组，用 Danger 色并写明后果。
- 只有不可撤销的操作才要求输入名称确认；能撤销的给撤销。

## 检查

- [ ] 搜索同义词能找到对应设置；设置链接能直接定位
- [ ] 立即生效的开关断网时改动会回滚并提示
- [ ] 显式保存的分组有未保存提示，离开前拦截
- [ ] 已修改项有标记，单项恢复默认可用
- [ ] 窄到 360px 时分类导航和返回路径清楚
