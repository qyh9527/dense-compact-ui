# 圆角与形状

## 意图

圆润的外轮廓界定独立对象和操作组；内部靠稳定基线、细边界和紧凑排列保持扫描效率。圆角和边界、间距一起说明「谁装着谁、谁和谁连着」。

不要每一层都配宽边距、大曲线、厚边框。有空间意义的容器才有轮廓；重复数据行一般共用所在区域的边界。已有产品保留其形状语言；新设计用少量 token，改圆角时按角色统一改，并检查同类组件与邻接关系。

## 按角色取值

起点沿用《Dense Compact UI Design Language》第 31 节。每个角色选一个稳定值，再按尺寸、字体和平台微调。

| 角色 | 起点 | 作用 |
| --- | --- | --- |
| 小型控件、独立标记 | 4–7px | 小对象轮廓清楚 |
| 普通按钮 | 6–9px | 圆润紧凑的操作轮廓 |
| 输入、选择控件 | 6–10px | 容纳文字，同组一致 |
| 独立区域、容器 | 8–14px | 界定区域 |
| 浮层、临时容器 | 按尺寸用容器尺度 | 与触发对象协调；小浮层可更小 |
| 标签、模式、选择胶囊 | full | 稳定的胶囊类别 |
| 共边接缝、连续数据边界 | 0 | 保持拼接线与扫描线 |

- 容器比内部控件圆；同类同尺寸同值。不要求每个角色都出现，也不要求每个角色独占一个值。
- 胶囊是有目的的类别。新设计里普通按钮用圆角矩形；已有产品统一用胶囊按钮时沿用。
- 圆形只给头像和明确的圆形操作；图标按钮是正方形不等于它该是圆形。

## 嵌套圆角

内表面贴近父容器的角、四边平行等距内缩时，让两条曲线近似同心：

```
内圆角 = max(0, 外圆角 − 内缩距离)
```

内缩距离从父表面外边缘量到子表面外边缘，计入边框、内边距和间隔，别漏算也别重复算边框。

| 走偏 | 改成 |
| --- | --- |
| 外 14px，内缩 4px，内层也 14px（内角显得鼓） | 内层 10px |
| 为凑公式给容器加 6px 内边距 | 不加；内容不贴角时按自身角色取值 |

只用于需要协调曲线的相邻内外表面。容器中央的按钮、输入框按自身角色取值。不等距内缩、方向不同的曲线、非圆弧形状逐角处理，再看实际预览。

## 共边组合与独立邻接

先判断边界是否真的连在一起：

- **共边**（分段控件、拼接区域）：整体外轮廓留圆角，内部接缝为 0，共享边框只画一次。
- **有间距的独立对象**：各留角色圆角，统一间距与基线。
- **贴住屏幕或容器边缘**：按实际可见外轮廓处理，贴边那侧不留圆角缺口。

宽窄屏改变排列方向时，重新判断哪些角在整体外侧。只有真实的容纳或组合关系才改边角。

## 圆角与内容、密度

- 大圆角配小内边距时，检查贴角的文字、图标、缩略图、首尾行背景和滚动条；优先局部调整形状或排列。
- 密度模式主要改间距和尺寸。控件变矮后复查圆角比例和可用宽度，保持形状类别，不让所有组件随视口变成胶囊。
- 选中、悬停、禁用、焦点沿用基础轮廓，状态由边界、表面和语义色表达。圆角 token 独立于配色，浅色、深色共用一套。

## 实现

- 用少量角色变量消费：`--dc-radius-control`、`--dc-radius-pane`、`--dc-radius-pill`；嵌套值按实际内缩局部推导。框架项目映射到其 shape token。
- 胶囊用大长度值（`9999px`）。`50%` 在非正方形上会变椭圆；圆形控件要等宽等高。
- 圆角背景不会自动裁切子内容。需要裁图片或滚动背景时在对应内容层处理，不给所有外容器加 `overflow: hidden`——它会裁掉焦点环、浮层和阴影。
- CSS 圆角会影响角部的指针命中。外框宽高够大不代表热区合格，按实际形状和相邻距离验收。
