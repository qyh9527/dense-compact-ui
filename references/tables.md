# 数据表格与列表

做表格页、列表页、日志列表、带选择和批量操作的数据视图时读。单元格里长内容怎么截断见 patterns.md 的「长内容」；实时刷新的表格另读 realtime.md；窄屏收列见 responsive.md。

## 结构与列宽

- 工具栏、表头、数据行同一档高度（dense 24px / compact 32px）；表头 `position: sticky` 固定，横向滚动时名称或 ID 列可固定在左侧。
- 列宽用 `rem` 或 `px`，不用 `em`：`em` 跟着表头的小字号算，表头和数据行会对不齐。
- 数字、状态、时间、操作列给固定宽度，按最长的真实值留位；名称列吃剩余宽度。每列有最小宽度，放不下就整表横向滚动，不把数字列挤到截断。
- 数字列右对齐 + `tabular-nums`，单位写在表头；文字列左对齐；状态列用图标或文字加颜色，不只靠颜色。
- dense 档行之间用 1px 分隔线，不再叠加斑马纹；悬停行用 Hover 底色，选中行用 Selection 底色，两者可同时辨认。
- 行内操作：最常用的 1–2 个直接显示，其余收进行尾「更多」菜单。鼠标设备可以悬停才显示，但键盘聚焦到该行时也要显示，触屏上常显。
- 点击行打开详情；行内按钮、复选框阻止事件冒泡，不误触打开。
- 空状态分两种：「还没有数据」给新建入口；「筛选后无结果」给「清除筛选」按钮。

## 排序、筛选与搜索

- 可排序表头用按钮，当前排序列标 `aria-sort="ascending"` / `"descending"`，其余列不标；默认排序也要在表头上看得出来。
- 已生效的筛选条件以标签显示在工具栏下方，每个可单独移除，另有「清除全部」；工具栏显示「共 N 条」。
- 搜索在输入停顿约 200–300ms 后再查询；匹配到的文字高亮。
- 排序、筛选、搜索词、分页写进 URL（见 patterns.md 的「导航与反馈」）。
- 服务端筛选慢于约 1 秒时，保留旧结果并标出「更新中」，不先清空表格再出骨架。

## 选择与批量操作

- 复选框列在最左；表头复选框三态（全选 / 部分选中用 `indeterminate` / 未选）。
- Shift + 点击选择范围；跨页时，表头全选只选当前页，再给一条「选择全部 N 条」的提示链接。
- 批量操作条出现在表格上方，与工具栏同高，显示「已选 N 项」和「清除选择」；窄屏可固定在底部，避开安全区。
- 删除、批量修改优先给「撤销」（toast 停留 5–10s，悬停或聚焦时暂停计时），不用确认弹窗；无法撤销的才确认，确认文案写明对象名和数量。
- 批量操作部分失败时，列出失败的条目和原因，成功的不回滚，失败的保持选中方便重试。

## 数据量与分页

分页和渲染策略分开定：分页看任务，渲染看实测成本。

- **分页按任务定。** 需要定位、回到某一页、和别人说「第 3 页那条」，或数据在服务端按需加载时用分页；用户要连续浏览、逐项比较或全量核对时，一页显示全部（见 layout-density.md 的「行模型」）。日志、动态这类连续流用「加载更多」或无限滚动，无限滚动的列表下方不放页脚内容。
- **渲染按成本选，依次升级：**
  1. 轻量行（文字加少量控件）直接全量渲染。几十到几百行通常不需要特殊处理。
  2. 行多到滚动或输入掉帧，或单元格很重（图表、富文本、编辑器）时，给行加 `content-visibility: auto` 和 `contain-intrinsic-size`，屏幕外的行跳过渲染。占位尺寸要接近真实行高；行会展开或高度不一时，占位和实际高度对不上，列表重建后恢复滚动位置会跳，这类列表优先全量渲染或虚拟滚动。
  3. 上千行或实测仍卡时用虚拟滚动，虚拟滚动要求行高固定（展开详情放到列表外的详情区）。
- 判断成本用 DevTools Performance 录一段滚动和输入，或看 Lighthouse 的 DOM 体积诊断（整页节点数，不是行数）。
- 分页器显示总数和当前范围（「101–150 / 1,240」），每页条数可选并记住。

## 行内编辑与列设置

- 双击或 Enter 进入编辑，Enter 或失焦保存，Esc 取消；编辑态和单元格同尺寸，不撑高行。
- 保存失败时恢复原值，单元格标错并给出原因和重试。
- 列可以显示 / 隐藏、调整顺序和宽度，设置存到本地并在下次打开时恢复；提供「恢复默认列」。
- 拖拽调列宽时，同时支持双击分隔线按内容自适应；列顺序的调整另给菜单方式。

## 键盘

- 只读表格保持普通 `table` 语义即可，行内控件按 Tab 顺序可达。
- 需要方向键在单元格间移动（类似电子表格）时，按 WAI-ARIA 的 Grid 模式实现：整张表只占一个 Tab 停靠点（roving tabindex），方向键移动，Enter 进入编辑或打开，Space 选择行。
- 方向键行间移动、`/` 聚焦搜索这类快捷键写在悬停提示里（见 patterns.md 的「快捷键与拖拽」）。

## 检查

- [ ] 用最长的真实名称、最大的金额、最长的状态文案测过，数字和状态没被截断
- [ ] 表头和数据行列宽对齐；横向滚动时固定列和表头仍然对齐
- [ ] 排序、筛选、搜索、分页刷新后保留；空数据和筛选无结果各有出路
- [ ] 全选三态正确；批量删除可撤销；部分失败有清单
- [ ] 分页的理由来自任务；虚拟化或 `content-visibility` 的理由来自实测；1,000 行以上滚动不卡顿
