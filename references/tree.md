## 结构

- 行高与工作台同档；每级缩进约 12–16px（dense 档 12px）；层级超过 3 级时显示缩进参考线。
- 展开箭头、类型图标、名称从左到右排列；箭头的点击区域与整行一样高。点击名称是选中或打开，点击箭头只展开 / 收起。
- 名称单行截断，文件名保留扩展名（中间省略），悬停和聚焦时显示全名。
- 选中（Selection 底色）、键盘焦点（焦点环）、当前打开的项（左侧细条或字重）三者分开显示。
- 行尾最多放 3 个操作图标，悬停或聚焦时显示，其余放进「更多」菜单；VS Code 的视图规范同样限制为 3 个。
- 空文件夹展开后显示一行「空」，不显示为没有子节点的叶子。

## 键盘与语义

按 WAI-ARIA 的 Tree View 模式实现：

- 结构：容器 `role="tree"`，节点 `role="treeitem"`，子节点组 `role="group"`；父节点带 `aria-expanded`，多选树在容器上加 `aria-multiselectable="true"`，节点用 `aria-selected`。
- 整棵树只占一个 Tab 停靠点（roving tabindex），焦点回到树时落在上次的节点或选中节点。
- ↑ / ↓ 移动；→ 展开，已展开时进入第一个子节点；← 收起，已收起时回到父节点；Home / End 到首尾；Enter 打开或执行默认操作。
- 输入字母跳到下一个以它开头的节点（连续输入按整个字符串匹配）；`*` 展开同级所有节点。
- 多选：Ctrl/⌘ + 点击切换单项，Shift + 点击选择范围，Space 切换焦点项。

## 操作

- 新建和重命名在行内进行：F2 或慢速双击进入重命名，默认只选中文件名、不选扩展名；Enter 确认、Esc 取消；重名或非法字符就地提示，不弹窗。
- 右键菜单与行尾「更多」菜单内容一致；触屏用长按或「更多」按钮。
- 删除优先进回收站并给撤销；批量删除写清数量。
- 拖放：
  - 落点有两种反馈：插入线表示放在两项之间，文件夹高亮表示放进去；不能放的位置显示禁止样式。
  - 悬停在收起的文件夹上约 500–800ms 自动展开。
  - 按住修饰键切换移动和复制时，指针旁提示当前是哪种。
  - 每种拖放都有菜单等效入口（「移动到…」「复制到…」）。
- 提供「在树中定位当前文件」；展开状态、选中项和滚动位置在刷新后保留。

## 大目录与过滤

- 子节点多或来自网络时懒加载：展开后先显示一行「加载中…」，失败时在该行给重试。
- 节点很多时，把可见节点展平成一个列表再做虚拟滚动；`aria-level`、`aria-setsize`、`aria-posinset` 需要显式写上，因为 DOM 里不再有完整层级。
- 过滤时保留匹配项的所有上级节点，高亮匹配文字；清空过滤后恢复原来的展开状态。

## 文件管理视图

- 列表、详情、网格视图可切换并记住；详情视图按 tables.md 处理排序和列宽。
- 路径面包屑每段可点击，点击空白处可切换成文本输入框直接编辑路径。
- 上传显示队列：每个文件有进度、可取消，失败的可单独重试；同名冲突让用户选「替换 / 保留两者 / 跳过」，并可「应用到全部」。
- 拖入文件到窗口时显示整个落点区域，并说明会放到哪个文件夹。
